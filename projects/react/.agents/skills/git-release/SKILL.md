# Git Release
Inspect git status, current branch and remotes. Avoid force pushes, destructive reset and mass checkout without explicit authorization. Keep commits scoped and describe testing. For multi-repo releases record SHA and dependency ordering; prepare rollback and changelog.

## Output contract
Provide: summary, files affected, tests run and results, risks/assumptions, and next steps. Do not claim a test passed unless executed. Read repository-local AGENTS.md and applicable project profile first.
