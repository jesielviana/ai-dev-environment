# Feature Delivery
Write acceptance criteria and affected repositories. Inspect current behavior and API contracts. Propose incremental plan and test strategy. Implement smallest coherent patch; run relevant checks; review diff; report changes, validation, open risks and rollback. Request approval before irreversible changes.

## Output contract
Provide: summary, files affected, tests run and results, risks/assumptions, and next steps. Do not claim a test passed unless executed. Read repository-local AGENTS.md and applicable project profile first.
