# Bug Investigation
Capture exact command, environment, error and expected behavior. Form hypotheses, run minimally invasive checks, isolate cause, apply smallest fix, add regression test and verify. Do not treat symptoms as root cause. Distinguish observed evidence from assumptions.

## Output contract
Provide: summary, files affected, tests run and results, risks/assumptions, and next steps. Do not claim a test passed unless executed. Read repository-local AGENTS.md and applicable project profile first.
